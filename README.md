510880只读策略参考工具。假设从2020年起空仓并严格执行R波段规则，不是实际账户，不连接券商、不自动交易、不登记资金或持仓。旧桌面账簿未上传。

## 使用

顶部每日收盘卡独立于策略状态及周二复盘，显示原始日线的收盘、开高低、前收和较上一交易日收盘的涨跌。不是实时行情，也不从周K反推日行情。涨跌不包含分红收益；除息日单独提示现金分红及价格跌幅口径。收盘前保留上个交易日数据，收盘后等待当日核验；先到数据标记为初步行情，不推进策略。休市显示最近交易日，旧格式快照缺少明细时留空，不编造价格。页面刷新失败时保留旧行情并明确报错。

### 交易日历的缓存与核验

日历正常每24小时核验一次，不跟随每次行情抓取。网络失败（含HTTP 403）按1、2、4、6小时退避，之后最多每6小时尝试；实际执行取决于云端任务排期。缓存及重试状态随快照保存，手机刷新不会绕过退避。

页面分别展示官方核验成功、已核验缓存可用、在线失败但备用可用、日历受阻；显示覆盖期限、最近成功核验和下次尝试时间，不把缓存命中伪装成在线成功。缓存超过7天未重新核验、当前日期未知、解析失败或官方日历冲突时停止生成新结果，保留此前结果作参考。7天是本工具的保守维护期限，不是交易所保证。冲突必须人工核对公告，不静默改写日期；新年度仍需获得并验证官方安排。

- 首页显示当前策略参考状态、待执行日期、来源核验与截至日期。
- 周K随已获取收盘数据更新；26/52周切换，鼠标悬停、触摸点选、左右/Home/End键查看明细。
- 周二复盘单独保存；每日走势变化不会把周三至周五纳入周二观察。
- 模拟成交按执行日已核验原始开盘价，委托加价1%只是可调整的限价参考，不是成交价或成交保证。
- 黄色是等待/初步结果，红色是受阻。来源获取成功不代表价格已交叉核验。
- 所有历史模拟交易标明回放。新分红、未知日历、来源冲突和已发布数据修订均阻断新增正式结果。

## 自动更新（北京时间）

工作日15:05～17:55每10分钟尝试，18:15～22:15每小时补查，09:35检查开盘模拟执行。使用上交所交易日历辨别休市。GitHub任务可能排队、延迟或因长期无仓库活动停用，不能保证准点。手机刷新仅重新读取已发布快照，不触发云端抓取；页面也会检查收盘日期及周二复盘是否过期。收盘数据落后且云端超过45分钟没有更新时显示维护提示。

首次结果先发布；若数据未确认或首次部署失败，同一次工作流启动独立恢复阶段，最多8次重新获取，每次尝试完成后间隔2分钟，确认后提前停止并再次部署。恢复阶段最长30分钟，不依赖下一次定时触发。串行发布避免旧任务覆盖新结果；恢复期间其他运行可能排队。恢复携带首次及后续检查状态，保留旧确认数据与分红/日历冲突锁，不通过降低核验标准恢复。

网络始终不可用、核验冲突或重试耗尽时，保留旧确认记录，只显示受阻/待核验，不假装完成复盘。恢复最终进程失败时不发布中途残留产物。网站部署与数据确认分别检查，任意一项未完成都不能报最终健康成功。外部数据源、GitHub未调度及整个平台故障不在工具可保证范围内；首页明确显示云端检查时间、两源行情日期及超过45分钟未恢复的提示，并提供所有者手动运行入口。

页面区分“策略已确认至”和“行情预览至”，来源HTTP成功不等于数据新鲜或已核验。网页刷新失败后，切换26/52周仍保持错误状态，只有下一次有效快照读取才能清除。周二正式记录不因周三图表更新而改写。

### 分红源失败与数据健康

网络失败保留连接/TLS等底层原因，不再把未下载页面描述为“分红表缺失”。仅连接/运行时失败可切换独立HTTPS客户端；HTTP拒绝不会绕过。响应仍需完整解析和交叉核验。

管理人实时表通过后记录真正核验时间。管理人暂不可用时，只有东方财富实时表与已审计分红完全一致、且管理人核验不超过24小时，才可降级继续正式计算并显示警告；不会把辅助源成功伪装成管理人刚刚成功。两源均失败或管理人核验超过24小时，仅在7天内有效缓存基础上生成待复核图表，不推进模拟仓位、R等待或正式复盘；无缓存或超过7天暂停。24小时/7天是保守维护阈值，不是数据源保证。新增分红、修订、解析失败锁定，必须双源与审计基准重新一致才解除；新事件仍须人工核验公告后更新基准。

诊断页面依然允许部署，独立的data-health任务在数据未确认时报告失败，避免把“部署成功”当作“复盘成功”。GitHub通知是否送达取决于账户通知设置，不承诺主动推送。

需要人工重跑时：Actions → Update strategy dashboard → Run workflow。无访问令牌放在网页中，无额外服务器。

## 数据与规则

`contract.json` 是网页规则契约；保护采用剩余持仓均价8%预警/8.5%退出，不是早期整轮权益E0版本。网页不宣称旧收益回测自动适用于该保护口径。

新浪完整历史及腾讯近期日线交叉核验；分红由东方财富与管理人表核对，接受事件基准来自既有审计；新事件需官方公告核验。上交所日历。公开接口不承诺永久可用或交易所级精确。

`baseline.json` 仅保存已审计历史指纹、交易日期、19次分红事实及8个复盘对照点，不含用户账户或整套原始日线。`market.cjs` 显式保留旧三源审计的一个收盘差异（2018-04-24）和三个成交量取整例外，其余必须匹配4296根历史指纹。未忽略新差异。

网站只发布计算结果、最近52周图示、模拟记录和诊断元数据。没有远程脚本/CDN依赖、统计追踪或登录功能。请勿用于商业行情再分发。

## 节假日与短周

- 周二休市、周一开市：周二收盘时间后使用周一行情复盘，不改为周三复盘。
- 周一和周二都休市：明确记录“本次普通复盘已跳过”，不消耗R等待、不解除冻结、不取消已锁定计划。
- 其余交易日照常更新日行情、周K和持仓保护。短周即使只有一至两天交易也计为完整周；整周休市不生成虚构K线，拟合取此前52个实际有交易的完整周。
- 普通执行仍在下一自然周首个已核验交易日；保护执行在下一已核验交易日。周末调休上班不等于证券交易所开市。
- 缺交易日行情、未知日历、日历冲突、历史指标不足不是“休市跳过”，保留旧状态并明确提示待核验。年度日历读取官方来源，覆盖不足不猜日期；官方网页改版或新增分红仍可能需要维护。

## 开发与验证

Node.js24，无npm运行时依赖：

```sh
node --test *.test.cjs
node cloud-probe.cjs
node build.cjs
```

`build.cjs`先读取上次发布快照；抓取失败时保留旧确认结果并发布异常状态，不能推进R等待或模拟持仓。测试快照带testOnly标志；GitHub运行时禁止本地fixture。

Windows PowerShell运行测试：`$testFiles = (Get-ChildItem -Filter '*.test.cjs').Name; node --test @testFiles`。恢复测试注入失败和虚拟等待，不发真实交易或在生产网站发布测试数据。

源码位于根目录；发布仅白名单复制UI文件与生成的snapshot.json到site目录。GitHub Actions一次性发布完整产物，计算任务仅有读取权限，部署任务仅限Pages所需权限，不写仓库。

本地821次历史复盘已与原独立基准及桌面内核对齐。这不等于长期云端可靠性已完成验收，也不保证实际券商成交。
